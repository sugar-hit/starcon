# Starcon 调度入口

从当前仓库根目录读取 `AGENTS.md` 和 `tools/module-progress/PIPELINE.md`，
按其中唯一执行协议运行。本文件不重复参数、worker 模板或检查命令。

先只读检查 `.dev-agent/PIPELINE.local.md`、git 状态、车道、当前失败与剩余额度。
缺本地配置、静默窗口内、过热、配额不足或任务仍被其他 worker 持有时，零派发并报告具体原因。
不要执行配置内 shell/eval，不改定时任务、用户并发/静默/温度阈值，不自动恢复暂停任务。

优先修复与收口；先查重和依赖，再按剩余容量派小任务。
worker 只跑受影响检查；集成后同一内容快照只做一次完整 L2，随后通过 PR 验收。
`land` 只是待验收，CI/测试证据缺失不能报告已交付。

仅汇报变化：验收行为与 SHA、失败命令/原因、下一任务、实际可读的用量。
不承诺固定完成日期，不虚构用量或质量结论。状态不变时不重复长报告或写重复会话日志。
