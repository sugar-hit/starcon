# 10 物流与头程系统

> **定位**：跨境履约的**物理链路**。尾程（买家配送）+ 头程（国内到海外）+ 报关清关，三段各自独立计费又必须对齐。
> **后端归属**：`channel` 拥有物流商连接与轨迹；`trade` 拥有运单与报关单据；`warehouse` 拥有包裹与装运。
> **前端入口**：`/logistics`

## 边界

**做**：物流渠道与承运商、物流比价与运费试算、运单申请、面单与轨迹、头程发运与在途、海外仓对接与预报、报关清关资料、交运批次、异常件处理。

**不做**：不决定发哪个仓（09 决定）、不计算利润（12/13 计算）、不处理退货逆向物流（11 发起、08 执行）。

**关键约束**：
- 包裹必须有明细项，不能只有重量和运单号
- 轨迹事件按承运商事件 ID **去重**
- 头程发出后进入**在途**，不是"发出即到仓"
- 报关资料由**实际发货单**生成，与销售订单解耦（一个订单可能拆多个报关批次）

## 功能职责（L2）

| 功能 | 职责 | 主责服务 |
|---|---|---|
| **10.1 物流渠道** | 维护承运商与渠道配置（计费、时效、限制），并提供运费试算与多目标比价 | channel |
| **10.2 运单管理** | 申请运单号、维护包裹与面单模板、处理改址与取消；运单状态以承运商侧为准 | trade + channel |
| **10.3 物流跟踪** | 采集轨迹并去重、识别异常件、组织交运批次与揽收签收确认 | channel |
| **10.4 头程管理** | 管理国内到海外的发运与在途跟踪、海外仓连接与备货预报；头程是货权与成本的关键节点 | trade + warehouse + channel |
| **10.5 报关清关** | 生成并提交报关三单据、维护申报要素、计算税费与贸易单证；错误直接导致扣货与罚款 | trade |
| **10.6 物流分析** | 分析物流与头程成本、渠道时效，用真实成本反哺定价测算 | trade + reporting 投影 |

## 详细设计

### 10.1.1.1 承运商列表

- **职责**：管理承运商（快递、专线、邮政、FBA 承运、末端派送）：接口类型、账号、覆盖国家、时效等级、支持业务类型（自发货/退货/FBA 入仓）。
- **输入**：承运商定义与接口配置；账号凭据（存密钥管理器引用）。
- **输出**：承运商档案 + 可用性状态。
- **关系**：上游 = 3.6.1.2 承运商角色档案；下游 = 10.1.1.2 渠道配置。**承运商是往来单位的一种角色**（实体目录 §3.5），不在此处重复建档。

### 10.1.1.2 渠道配置

- **职责**：配置具体物流渠道：所属承运商、渠道代码、适用店铺/国家/品类、计费方式（按重/按件/按体积）、附加费（燃油、偏远、旺季）、申报限制、保价规则。
- **输入**：渠道定义；计费与附加费参数；限制条件。
- **输出**：渠道配置；供运费试算与自动匹配使用。
- **关系**：上游 = 10.1.1.1；下游 = 10.1.2.2、9.3.2.1、10.2.1.2。**渠道限制（禁限品类、电池液体、磁力）要硬拦截**，否则会被承运商拒收产生额外费用。

### 10.1.1.3 时效与限制

- **职责**：维护渠道时效（分国家分重量段）与限制（尺寸上限、重量上限、禁限品类、电池/液体/危险品标记要求），并在选品与刊登阶段提示。
- **输入**：时效与限制规则；SKU 属性（3.7.2 安全属性）。
- **输出**：时效估算；限制命中提示。
- **关系**：上游 = 10.1.1.2、3.7.2；下游 = 5.3.1.1 测算（时效影响转化）、4.2.3.2 合规预检。

### 10.1.2.1 运费计算器

- **职责**：输入收货国家、重量、体积、件数、申报价值、是否带电/液体等，输出各可用渠道的运费与预计时效，供人工决策或规则匹配使用。
- **输入**：包裹参数；渠道规则集；可能的附加费。
- **输出**：渠道 × (运费、时效、可承运性) 对照表。
- **关系**：上游 = 10.1.1.2；下游 = 9.3.2.1 分仓、5.2.3.2 费用测算。**试算用规则、结算用实际**，两者差异进费用差异项——不能拿试算当实际成本。

### 10.1.2.2 渠道比价

- **职责**：在满足时效与限制的渠道中按成本/时效/成功率多目标排序，支持按店铺预设优先级自动选择。
- **输入**：比价条件；渠道评分（历史成功率、时效达成率、投诉率）。
- **输出**：排序后的推荐渠道 + 评分明细。
- **关系**：上游 = 10.1.2.1、10.6 时效分析；下游 = 9.3.2.1 分仓、18 自动化规则。**只看价格选渠道是常见错误**：便宜但高丢件的渠道会推高售后与差评成本。

### 10.2.1.1 运单列表

- **职责**：运单主列表：运单号、订单/包裹、承运商渠道、发货仓、状态（待取号/已取号/已揽收/运输中/已签收/异常/已取消）、下单时间、重量、运费。
- **输入**：筛选条件（渠道、状态、时间、目的国）；用户数据范围。
- **输出**：列表 + 批量操作（申请运单、取消、打印）。
- **关系**：上游 = 8.3.4.1、10.2.1.2；下游 = 10.3.1.1 轨迹。**运单状态从承运商侧获取为准**，内部状态仅作展示。

### 10.2.1.2 运单申请

- **职责**：向承运商申请运单号：传入收寄信息、包裹明细、申报信息，支持批量申请、失败重试、接口限流控制。
- **输入**：待发货包裹；渠道；申报信息（3.7 报关属性）；`idempotency_key`。
- **输出**：运单号 + 面单数据；失败原因。
- **关系**：上游 = 9.4.1.1、8.3.4.2；下游 = 10.2.2.1、10.3.1.1。**批量申请要按渠道限流排队**，否则触发接口限流影响整批。

### 10.2.1.3 改址与取消

- **职责**：处理运单层面的改址（部分渠道支持且有时限）与取消，联动订单地址变更与平台通知。
- **输入**：改址/取消请求；渠道规则与时限。
- **输出**：渠道操作结果；订单地址变更记录；买家通知任务（15）。
- **关系**：上游 = 10.2.1.1、9.1.1.3；下游 = 承运商接口、15 客户与客服。**改址是买家高频诉求**，超时的改址请求要明确告知能否成功而不是让客服猜。

### 10.2.2.1 包裹详情

- **职责**：单包裹视图：包裹内 SKU 与数量（parcel_item）、订单行对应关系、重量体积、面单、轨迹、交运信息。
- **输入**：`parcel_id`；关联订单行与轨迹。
- **输出**：包裹详情 + 操作入口。
- **关系**：上游 = 8.3.3.2；下游 = 10.3.1.1、12 财务（运费成本归集）。**parcel_item 与订单行的对应关系是成本归集到行的基础**，缺了就只能算到订单级。

### 10.2.2.2 面单模板

- **职责**：维护面单模板与打印规格（尺寸、条码类型、附加声明、电池标识、语言版本），支持按渠道与国家配置。
- **输入**：模板定义；渠道要求。
- **输出**：模板 + 打印任务（经 8.3.4.2）。
- **关系**：上游 = 10.1.1.2；下游 = 8.3.4.2 打印。**附加声明（如电池、液体）漏打会导致清关问题**，模板配置要与渠道规则强绑定。

### 10.3.1.1 轨迹查询

- **职责**：查询并展示包裹物流轨迹：节点时间线（揽收-运输-清关-转运-派送-签收）、预计时效对比、异常节点标记，支持按承运商批量拉取。
- **输入**：运单/包裹集合；承运商轨迹接口；轮询任务。
- **输出**：轨迹时间线 + 预计到达时间 + 异常标记。
- **关系**：上游 = 承运商 API；下游 = 10.3.1.2、15 客服（查询应答）、13 分析。**按承运商事件 ID 去重**，同一节点重复推送不产生重复记录。

### 10.3.1.2 异常件

- **职责**：识别与处理异常件：轨迹停滞、妥投失败、地址问题、清关滞留、破损丢件、买家投诉；支持联系承运商、发起理赔、改址、补发。
- **输入**：轨迹异常规则；被动异常标记；客服反馈。
- **输出**：异常件清单 + 处置记录 + 理赔/补发单。
- **关系**：上游 = 10.3.1.1；下游 = 11 售后（补发/退款）、15 客服、7 库存（补发出库）。**异常件必须有人负责到底**，否则变成买家差评与平台纠纷。

### 10.3.2.1 交运批次

- **职责**：把已发货包裹按承运商与交运时间组批，交接给承运商并登记交接清单，减少交接差错。
- **输入**：包裹集合；承运商；交运时间。
- **输出**：交运批次 + 交接清单 + 承运商回执。
- **关系**：上游 = 9.4.1.1；下游 = 承运商接口、10.3.2.2。**批次交接是责任分界点**：批次内包裹的丢失责任在承运商，需要交接清单留证。

### 10.3.2.2 揽收与签收确认

- **职责**：确认承运商揽收（避免超时未揽收被平台判未发货）与签收（触发售后窗口关闭与评价邀请时机）。
- **输入**：承运商揽收/签收事件；SLA 时限。
- **输出**：状态更新 + 提醒任务。
- **关系**：上游 = 10.3.1.1；下游 = 9.4.2.1 回传、15 客服（邀请评价）。**揽收状态直接影响平台履约指标**，需主动监控而非等轨迹同步。

### 10.4.1.1 头程发运单

- **职责**：管理国内到海外的货权转移发运：选择货物与批次（国内仓/供应商）、选择运输方式（海运/空运/铁运/快递）、申报信息、目的仓、预计到港时间、成本预估。
- **输入**：待发运货物清单；运输方式与渠道；报关资料；成本参数。
- **输出**：头程发运单 + 发货分录（转在途）+ 报关资料 + 预计到港时间。
- **关系**：上游 = 8.2.1.1 收货、6 采购；下游 = 10.5 报关、7.5.1.2 在途。**头程发运是货权与成本的关键节点**：从这一刻起成本转嫁方式（FOB/CIF）与风险承担方确定，直接影响利润口径。

### 10.4.1.2 在途跟踪

- **职责**：跟踪头程在途：位置、预计到港、延误预警、清关状态、目的仓收货确认，节点异常主动告警。
- **输入**：货代/船司/清关状态同步；人工更新。
- **输出**：在途看板 + 延误预警 + 到港提醒。
- **关系**：上游 = 10.4.1.1；下游 = 7.5.1.2 在途库存、6.2.1.1 补货（缺口计算）。**头程延误是断货的主要外因**，预警必须提前到预计到港前若干天。

### 10.4.2.1 海外仓连接

- **职责**：对接海外仓/第三方仓服务商：连接授权、库存同步、订单预报、收发状态回传、账单对接；管理多仓服务商下的仓账户。
- **输入**：服务商接口配置；库存同步任务；订单推送。
- **输出**：连接状态 + 同步记录 + 仓账户列表；外部库存观测数据。
- **关系**：上游 = 2 渠道机制、9.3.2.2；下游 = 7.1.3.1 多仓分布、12 财务（海外仓账单）。**外部仓库存是观测值不是自有账本**，必须与自营库存分开存储与对账，不能覆盖。

### 10.4.2.2 备货预报

- **职责**：向海外仓/平台仓提交备货计划：SKU 与数量、目的仓、期望到货时间、平台货件编号，接收仓端接收与拒收反馈。
- **输入**：FBA 发货计划或海外仓备货需求；库存与在途数据；平台货件要求。
- **输出**：预报单 + 平台货件创建任务 + 仓端回执。
- **关系**：上游 = 6.2.1.2 补货建议、7 在途；下游 = 2 平台接口（创建货件）、10.4.2.1。**平台仓备货有严格规格**（箱型、贴标、托盘、混装限制），规格不符会被拒收造成额外成本与延误。

### 10.5.1.1 报关单管理

- **职责**：管理报关单：按发货单生成申报资料（报关单、装箱单、发票），提交报关行/IOR，接收放行、退单、改单结果。
- **输入**：发货明细；3.7.1.1 HS 编码与申报要素；货值与汇率快照；贸易方式与收发货人信息。
- **输出**：报关单 + 三单据 + 报关行提交结果 + 放行/异常状态。
- **关系**：上游 = 10.4.1.1、3.7 报关属性；下游 = 10.5.1.3 关税、12 财务（成本）、16 合规。**报关数据错误导致的扣货与罚款由卖家承担**，因此必须有人工复核节点（实体目录 §9 与业界共识）。

### 10.5.1.2 申报要素

- **职责**：维护申报所需的品名、规格材质、用途、品牌、数量、单价、币种、产地、原产地规则（RCEP/优惠税率适用），支持按目的地国家差异化。
- **输入**：3.7.1.2 目的地报关版本；批次实际信息。
- **输出**：完整申报要素集；缺失项提示。
- **关系**：上游 = 3.7.1.2；下游 = 10.5.1.1。**申报品名不能照搬销售标题**，两者用途不同（前者为清关，后者为转化），混用是常见被退单原因。

### 10.5.1.3 关税与税费

- **职责**：计算与管理进口税费：关税（按 HS 编码税率）、增值税/GST、关税承担方（DDP/DDU）、到岸成本构成，供成本核算与报价参考。
- **输入**：HS 编码税率表；目的国税则；申报价值；贸易条款。
- **输出**：税费估算 + 实际缴纳记录；到岸成本明细。
- **关系**：上游 = 10.5.1.1、16 合规（税则）；下游 = 5.2.1.2 到岸成本、12 财务。**税费估算与实际缴纳差异要记录**，长期差异大说明 HS 归类或税率配置有误。

### 10.5.2.1 贸易单证

- **职责**：管理与生成贸易相关单证：商业发票、装箱单、原产地证（RCEP/CO/FTA 优惠）、提单/空运单、进口许可与认证文件，按目的地国家规则校验完整性。
- **输入**：发货明细；目的地国家单证要求；16 合规的认证状态。
- **输出**：单证文件 + 完整性校验结果 + 缺失提醒。
- **关系**：上游 = 10.5.1.1、16 合规；下游 = 报关行/目的仓提交。**FTA 优惠原产地证能显著降低关税**，其适用条件（尤其是"实质性改变"）需要业务确认，系统只负责按规则校验与留档。

### 10.6.1.1 成本分析

- **职责**：分析物流成本：单位重量/单均运费、头程分摊后到岸成本占比、各渠道成本对比、超成本订单识别、头程费用分摊明细。
- **输入**：实际运费与头程费用；包裹与发运记录。
- **输出**：成本报表 + 分摊明细 + 异常订单清单。
- **关系**：上游 = 10.2、10.4、12 财务；下游 = 5 定价、13 利润。**物流成本常被低估**：真实成本 = 尾程 + 头程分摊 + 包材 + 关税 + 仓储费，报表必须全口径。

### 10.6.2.1 时效分析

- **职责**：分析时效表现：各渠道各国家的妥投率、超时率、平均时效波动、旺季变化，用于渠道评分与时效承诺设置。
- **输入**：轨迹数据；承运商承诺时效。
- **输出**：时效报表 + 渠道评分 + 异常集中分析。
- **关系**：上游 = 10.3.1.1；下游 = 10.1.2.2 比价、9.5.1 订单时效。**时效数据要按渠道和国家交叉分析**，总体平均会掩盖某些渠道在某些国家的系统性延误。
