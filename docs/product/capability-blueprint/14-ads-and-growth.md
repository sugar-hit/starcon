# 14 广告与增长系统

> **定位**：广告是利润的一等组成，不是"费用科目"。这里负责投放执行与效果归因，并把结果回灌到定价与利润。
> **后端归属**：`channel` 服务负责平台广告 API 对接；`reporting` 负责报表；促销与联盟归 14 内的增长模块。
> **前端入口**：`/ads`

## 边界

**做**：广告活动与广告组管理、关键词与投放定位、竞价与预算管理、批量调价规则、广告报表与归因、促销与优惠券、联盟与达人建联、站外推广。

**不做**：不替代广告平台本身做全量投放（ERP 侧是管理与同步）、不把广告费直接当销售成本（需按 12 的分摊规则处理）。

**关键约束**：

- **广告数据从平台同步，不从人工填写**——手填必然失真
- 广告费必须能**归因到 SKU/订单/活动**，否则利润算不准
- 批量调整预算与竞价要走规则并留审计，AI/规则自动调整必须有上限保护
- **TACOS 与 ROAS 口径要写明**（ACOS vs ROAS vs TACOS 混用是行业常见错误）

## 详细设计

### 14.1.1.1 活动列表

- **职责**：广告活动主列表：平台、店铺、活动名、类型、状态、预算、消耗、曝光、点击、订单、销售额、ACOS/ROAS，按维度筛选与排序，支持批量暂停/启用/调预算。
- **输入**：筛选条件（平台、店铺、状态、日期）；广告数据同步结果；用户数据范围。
- **输出**：分页列表 + 汇总；批量操作任务。
- **关系**：上游 = 平台广告 API 同步；下游 = 14.1.1.2 详情、14.2.2.1 预算。**广告数据同步是本系统的地基**：同步失败时页面要明确显示"数据截至 X 时间"，不能用空数据假装没有投放。

### 14.1.1.2 活动详情

- **职责**：单活动全景：基本设置、预算与消耗曲线、广告组列表、投放商品、关键词、创意（视频/图片）、每日表现明细、平台侧修改历史。
- **输入**：`campaign_id`；聚合子资源。
- **输出**：详情视图 + 操作入口（调预算、改竞价、暂停、复制结构）。
- **关系**：上游 = 14.1.1.1；下游 = 14.1.2.1 广告组、14.3.1.1 报表。**"复制结构"是高价值操作**：把跑得好的活动结构复制到新店铺/新 ASIN，是广告提效的核心动作。

### 14.1.1.3 批量操作

- **职责**：跨活动批量调整：预算增减、竞价调整、状态切换、结束时间设置，支持按筛选结果全选并预览变更。
- **输入**：选中活动集合；调整参数；预览确认。
- **输出**：批量调整任务（异步）+ 每条执行结果。
- **关系**：上游 = 14.1.1.1；下游 = 平台广告 API（经 2 队列）。**批量调价要有单次上限与总消耗上限保护**，误操作一次可能烧掉整月预算。

### 14.1.2.1 广告组管理

- **职责**：管理广告组：关联投放商品、匹配类型、定向设置、默认竞价，查看组级表现。
- **输入**：广告组设置；关联商品选择（从 4 listing 中选）。
- **输出**：广告组记录 + 组级报表入口。
- **关系**：上游 = 14.1.1.2；下游 = 14.1.3.1 关键词、14.2.1.1 竞价。**广告组与 SKU 的映射是利润归因的基础**——投放的是 listing，归因要落到内部 SKU。

### 14.1.2.2 广告类型差异

- **职责**：适配不同平台与广告类型的字段差异（自动广告、SB/SD、品牌广告、DSP、大促广告），把差异字段归一到内部模型展示。
- **输入**：各平台广告类型定义；平台 API 返回。
- **输出**：归一后的广告类型视图 + 特有字段补充展示。
- **关系**：上游 = 2.1.2.1 平台映射；下游 = 14.1.1.1。**归一化让跨平台广告可比**，但必须保留原始类型标记，不能丢信息。

### 14.1.3.1 关键词管理

- **职责**：关键词管理与分析：搜索词报告、关键词表现（展示、点击、转化、CPC、ACOS）、否定词建议、词频与排名、批量调价与否定。
- **输入**：搜索词与关键词数据同步；批量操作参数。
- **输出**：关键词报表 + 否定建议 + 批量调整任务。
- **关系**：上游 = 平台搜索词报告；下游 = 14.2.1.1 竞价、4.5.1.2 排名。**搜索词报告是发现浪费的入口**：高曝光零转化词应尽快否定，否则预算持续流失。

### 14.1.3.2 投放定位

- **职责**：管理投放定位（地域、人群、设备、时段、匹配类型），支持按定位维度看效果，指导出价调整。
- **输入**：定位设置；定位维度效果数据。
- **输出**：定位效果对比表 + 调整建议。
- **关系**：上游 = 14.1.2.1；下游 = 14.2.1.2 分时策略。**定位效果差异大时应收窄投放**，无效定位的花费是最容易省下来的钱。

### 14.2.1.1 竞价管理

- **职责**：管理竞价：动态竞价策略选择（只增只降/降低/提高）、手动竞价调整、竞价范围上限、按商品/SKU 的目标 ACOS 反推竞价建议。
- **输入**：竞价设置；目标 ACOS/ROAS；历史表现。
- **输出**：竞价建议（目标 ACOS → 建议竞价）；批量调整任务。
- **关系**：上游 = 14.1.3.1、14.3.2.1；下游 = 平台广告 API。**目标 ACOS 反推竞价是广告与利润打通的接口**——没有利润数据，投放只能看平台给的建议，无法判断是否真的赚钱。

### 14.2.1.2 分时策略

- **职责**：按小时设置不同竞价与预算（高峰提价提预算、低谷降价停投），支持按历史出单时段自动推荐分时曲线。
- **输入**：分时规则；13.2.1.2 时段分布数据。
- **输出**：分时策略配置 + 定时调整任务。
- **关系**：上游 = 13.2.1.2；下游 = 14.2.2.2 自动规则。**分时策略需按店铺时区配置**，跨时区店铺用错时区会完全失效。

### 14.2.2.1 预算分配

- **职责**：跨店铺/跨活动的预算分配与再平衡：按销售目标、利润、历史 ROAS 分配预算，识别预算受限的活动与闲置预算。
- **输入**：预算总额；分配规则；各活动历史表现。
- **输出**：分配方案 + 再平衡建议 + 执行任务。
- **关系**：上游 = 14.1.1.1、13.4 利润；下游 = 14.2.2.2。**预算应向利润高的活动倾斜**，按销售额平均分配是常见浪费。

### 14.2.2.2 自动规则

- **职责**：自动化规则：按条件自动调整预算/竞价/启停（ACOS 超标降价、ROAS 达标加预算、消耗完毕暂停、花费无转化停投），支持规则优先级、单次调整上限与总上限、试运行模式。
- **输入**：规则定义；实时广告表现；上下限保护参数。
- **输出**：规则命中记录 + 调整执行记录 + 效果回溯。
- **关系**：上游 = 14.3 报表；下游 = 平台广告 API。**自动规则必须有上限与试运行**——没有上限的自动调价一次异常就能烧掉大量预算。

### 14.3.1.1 活动报表

- **职责**：活动维度效果报表：花费、曝光、点击、CTR、CPC、订单、转化率、销售额、ACOS/ROAS/TACOS，按日/周/月与多维对比，支持导出。
- **输入**：时间范围；维度；广告数据。
- **输出**：报表表 + 趋势图 + 口径说明。
- **关系**：上游 = 14.1.1.1；下游 = 14.3.2.1。**ACOS/ROAS/TACOS 三个口径要在表头写明定义**，否则跨部门沟通会各说各话。

### 14.3.1.2 广告组与词报表

- **职责**：广告组与关键词维度报表：单组/单词效果、搜索词质量、否定效果评估，支持批量选中导出。
- **输入**：维度选择（组/词/搜索词）；时间范围。
- **输出**：明细报表 + 汇总。
- **关系**：上游 = 14.1.3.1；下游 = 14.1.3.1 否定决策。**关键词级数据量极大**，查询必须分页与缓存，不能实时全表扫。

### 14.3.1.3 商品维度报表

- **职责**：商品维度广告效果：SKU/SPU/Listing 维度的广告花费、广告销售额、总销售额、ACOS、TACOS、广告占比利润。
- **输入**：商品维度；时间范围；利润数据（13）。
- **输出**：商品广告报表 + 广告销售占比 + 广告后净利。
- **关系**：上游 = 14.3.1.1、13.4.1.2；下游 = 13.4 利润。**广告销售占比（广告单/总单）是判断广告是否带来增量还是抢自然单的关键**，只看广告 ROAS 无法回答这个问题。

### 14.3.2.1 归因分析

- **职责**：广告归因：把广告花费归因到 SKU/订单（支持平台归因窗口口径），计算广告后净利、TACOS、增量效果估计。
- **输入**：平台广告归因数据；订单数据；利润数据；归因规则配置（末次点击/平台归因窗口）。
- **输出**：归因明细 + 广告后利润报表。
- **关系**：上游 = 14.3.1.3、13.4.1.2；下游 = 13.4 利润、5 定价。**归因规则必须固定并公示**，规则变了历史报表不可比——这是广告与财务对账最容易吵架的点。

### 14.3.2.2 效率诊断

- **职责**：诊断投放效率问题：高花费零转化、ACOS 长期超标、预算受限、竞价过低曝光不足、创意衰退，给出可执行建议与一键调整。
- **输入**：14.3 报表指标；诊断规则。
- **输出**：诊断清单 + 建议动作。
- **关系**：上游 = 14.3.1；下游 = 14.2.1.1、14.1.3.1。**诊断要给动作而不是只报警**，否则用户看完还是要自己想怎么办。

### 14.4.1.1 促销列表

- **职责**：管理平台促销活动：促销类型、适用商品、折扣幅度、起止时间、预算上限、参与店铺，同步状态与效果。
- **输入**：促销定义；平台促销接口；适用商品选择。
- **输出**：促销记录 + 平台同步状态。
- **关系**：上游 = 5 定价（促销价计算）；下游 = 平台促销 API、12 财务（费用）。**促销的毛利必须实时测算**——折扣叠加后亏损是常态，需在下单前拦截或预警。

### 14.4.1.2 优惠券与秒杀

- **职责**：管理优惠券（折扣码、满减、买赠）与秒杀活动：生成码、设置库存与限领、投放渠道（站内/站外/社媒），跟踪领取与核销。
- **输入**：券规则；投放计划；核销数据同步。
- **输出**：券记录 + 核销统计。
- **关系**：上游 = 5 定价；下游 = 平台营销接口、15 客户（定向发放）。**券的核销要与订单绑定**，否则无法评估活动真实效果与补贴成本。

### 14.4.2.1 促销效果分析

- **职责**：促销效果分析：促销期间销量/销售额/毛利变化、增量判断、补贴成本、ROI，与活动前的基期对比。
- **输入**：促销数据；历史基线；利润数据。
- **输出**：效果报表 + 增量估算 + ROI。
- **关系**：上游 = 14.4.1；下游 = 13.4 利润、14.2.2.1 预算。**促销期间毛利可能大幅下滑**，评估必须看毛利而不是销售额。

### 14.5.1.1 达人库

- **职责**：管理达人/联盟资源：达人档案（类目、粉丝层级、带货 GMV、互动率、合作历史）、标签分组、评级与黑名单。
- **输入**：达人数据同步（平台接口或手动录入）；标签与评级。
- **输出**：达人库 + 筛选检索。
- **关系**：上游 = 平台数据；下游 = 14.5.1.2 建联、15 客户与客服。**达人效果数据（GMV/退款率）必须入库**，否则无法筛选优质达人。

### 14.5.1.2 建联与样品

- **职责**：达人建联流程：按规则筛选达人 → 模板化私信邀约（走官方接口）→ 寄样管理（样品单、物流、签收）→ 合作跟进 → 佣金设置。
- **输入**：达人筛选条件；邀约模板；样品寄送信息；佣金比例。
- **输出**：建联记录 + 样品单 + 合作状态跟踪。
- **关系**：上游 = 14.5.1.1；下游 = 8 仓库（样品出库）、10 物流（样品物流）、12 财务（佣金计提）。**建联必须走官方接口**，批量私信是平台风控重点，第三方工具易导致账号风险。

### 14.5.2.1 带货归因

- **职责**：达人带货归因：达人带来的订单量、GMV、退款率、佣金成本、有效粉丝转化，对比达人投入产出，沉淀优质达人库。
- **输入**：达人带货数据同步；订单归因；佣金数据。
- **输出**：达人效果报表 + ROI + 评级更新。
- **关系**：上游 = 14.5.1.1、平台数据；下游 = 14.5.1.1 评级、13.4 利润（佣金成本）。**达人佣金是真实成本，必须进利润表**，否则会高估达人带货的净收益。
