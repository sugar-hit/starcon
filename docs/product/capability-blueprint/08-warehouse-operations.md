# 08 仓储作业系统

> **定位**：仓库**现场**怎么干活。收货、上架、拣货、复核、打包、发货——这里的每一次动作最终都变成 07 的一条库存分录。
> **后端归属**：`warehouse` 服务（拥有 `warehouse` `warehouse_location` `goods_receipt` `outbound_order` `pick_task` `parcel` `assembly_order` 等）。
> **前端入口**：`/warehouse`

## 边界

**做**：仓库与库位档案、收货与上架、拣货与复核、打包与面单打印、发货交接、出库单管理、组装/加工单、仓库作业绩效。

**不做**：不判定可售量（07 算好了）、不决定发哪个仓（09 分仓决定）、不处理退货判定（11 决定，08 执行收货）。

**关键约束**：
- 拣货完成 **≠** 已发货，两者状态必须分开
- 拣货必须记录**实际库位/批次/序列号**，不能只记 SKU 与数量
- 实物套装组装与虚拟套装扣组件**是两种不同动作**（虚拟套装无组装单）
- 所有作业动作与库存分录**在同一本地事务**完成

## 功能职责（L2）

| 功能 | 职责 | 主责服务 |
|---|---|---|
| **8.1 仓库与库位** | 维护仓库档案与行为配置、库位层级与自动分配；仓库绑定法人是财务与货权的基础 | warehouse |
| **8.2 入库作业** | 执行收货（预期 vs 实收、差异处理）与上架、待检流转；是库存增加的唯一现场入口 | warehouse |
| **8.3 出库作业** | 执行拣货、复核、打包、发货交接与面单打印；是库存减少的唯一现场入口 | warehouse |
| **8.4 组装作业** | 处理实物套装的组装与拆解（消耗组件产生成品），与虚拟套装扣组件严格区分 | warehouse |
| **8.5 仓库分析** | 提供作业人效、库位利用率与出库时效分析，支撑排班与绩效核算 | warehouse + reporting 投影 |

## 详细设计

### 8.1.1.1 仓库列表

- **职责**：展示租户下所有仓库：类型（自营/三方/海外仓/平台仓/监管仓）、所属法人、国家地区、时区、启用状态、库存量与作业量，支持筛选与新增。
- **输入**：筛选条件（类型、法人、国家）；用户数据范围；`warehouse` 与库存聚合。
- **输出**：仓库列表 + 关键指标；点击进入详情。
- **关系**：上游 = 17 法人；下游 = 8.1.1.2 详情、9 订单分仓、7 库存。**仓库绑定法人是财务前提**：不同法人的库存货权与收入归属不同。

### 8.1.1.2 仓库详情

- **职责**：单仓库全景：基础信息与地址、库位结构、库存分布、作业统计、关联的自发货/中转/FBA 备货策略、作业人员与设备。
- **输入**：`warehouse_id`；关联数据聚合。
- **输出**：详情视图 + 各子模块入口。
- **关系**：上游 = 8.1.1.1；下游 = 8.1.2 库位、8.2/8.3 作业、7.1.1.2 库存。**详情页是仓库的控制塔**，作业入口与库存入口都在这里。

### 8.1.1.3 仓库配置

- **职责**：配置仓库行为参数：是否支持批次/序列号、拣货策略（按订单/按波次/按库位）、默认复核比例、是否允许拆零发货、工作时段与班次。
- **输入**：配置项修改。
- **输出**：生效配置；影响 8.3 作业行为。
- **关系**：上游 = 8.1.1.2；下游 = 8.3.2 拣货、8.3.3 复核。**配置影响作业方式**，不是纯展示项，修改需记录变更。

### 8.1.2.1 库位树

- **职责**：维护库位层级与属性（区 → 巷 → 排 → 架 → 层 → 格），支持容量、承重、类型（存储/暂存/待检/残次/冻结）、是否可拣。
- **输入**：库位增删改与层级调整；防环校验。
- **输出**：库位树 + 占用情况。
- **关系**：上游 = 8.1.1.2；下游 = 8.1.2.2 自动分配、8.3.2.1 拣货路径。**库位不能跨租户引用**，也不允许跨仓库（实体目录 warehouse 段）。

### 8.1.2.2 库位自动分配

- **职责**：按规则为入库商品推荐库位：同品类聚类、最短上架路径、容量与承重匹配、待检/残次专用库位强制规则。
- **输入**：入库 SKU 与数量；库位属性与占用；路径距离。
- **输出**：推荐库位列表（带推荐理由）。
- **关系**：上游 = 8.1.2.1、8.2.1.1；下游 = 8.2.2.1 上架任务。**质量状态决定库位类型**：残次品入残次库位是硬规则，不允许混放。

### 8.2.1.1 收货单

- **职责**：执行到货收货：选择来源（采购/退货/调拨/平台仓回货），录入实收数量与差异，上传收货凭证，生成入库分录。
- **输入**：来源单据（6 采购单/11 退货授权/7.5 调拨单）；实收明细（SKU、数量、批次、序列号、效期）；差异原因。
- **输出**：收货单（草稿/已收/部分收/已关闭）+ 库存入库分录（转入待检或可售 bucket）。
- **关系**：上游 = 6 采购、11 售后、7.5.1.1；下游 = 7.1.2.1 流水、6.3.2.2（更新已收）、12 应付（收货确认）。**预期与实收分开记录**，超收/少收/拒收都要留痕并回写采购单。

### 8.2.1.2 收货差异

- **职责**：处理收货差异：短少、破损、型号不符、过期、错发；支持拍照留证、拒收、部分接收、索赔发起。
- **输入**：差异明细；处理决定；凭证。
- **输出**：差异处理记录 + 索赔单（6 采购）+ 库存拒收不入账记录。
- **关系**：上游 = 8.2.1.1；下游 = 6.4.2 不良品处理、6.5.1 对账索赔。**破损与短少必须拒收或待检入库**，直接入可售会把问题货卖出去。

### 8.2.2.1 上架任务

- **职责**：把已收货物从收货暂存位上架到正式库位，生成上架任务派发给作业人员（支持 PDA/扫码）。
- **输入**：待上架清单；库位推荐或指定库位；作业人员分配。
- **输出**：上架任务（待执行/执行中/完成）；库存 bucket 位置变更。
- **关系**：上游 = 8.2.1.1、8.1.2.2；下游 = 8.3.2.1 拣货。**上架只改位置不改数量**，数量在收货时已确定。

### 8.2.2.2 待检处理

- **职责**：管理待检区库存：发起质检任务（6 质检单）、质检通过后转入可售、质检不通过转残次/报废/退货。
- **输入**：待检库存清单；质检结果；处置决定。
- **输出**：质量状态变更分录；可售量更新。
- **关系**：上游 = 8.2.1.1、6.4.2.1；下游 = 7.1.1.3 可用量、6.4.2.2。**待检品不可售**是硬规则，质检通过前不能被销售预占。

### 8.3.1.1 出库单列表

- **职责**：出库作业主列表：来源（销售/采购退货/调拨/加工出库）、SKU 行数、件数、状态（待拣/拣货中/待复核/待打包/待发货/已发货/取消）、发货仓、承运渠道。
- **输入**：筛选条件（仓库、来源、状态、时间）；用户数据范围。
- **输出**：分页列表 + 批量操作（生成拣货任务、打印、取消）。
- **关系**：上游 = 9 订单履约需求、7.5.1.1 调拨；下游 = 8.3.2.1 拣货。**出库单 ≠ 销售订单**：一订单可多出库单（分仓/分批），出库单是履约动作的载体。

### 8.3.1.2 出库单详情

- **职责**：单出库单作业视图：明细行与已拣/已发量、关联销售订单与买家地址、预占引用、包裹列表、作业时间线。
- **输入**：`outbound_order_id`；关联对象。
- **输出**：详情 + 作业操作入口。
- **关系**：上游 = 8.3.1.1；下游 = 8.3.2.1、8.3.3.1、8.3.4.1。**详情页串联整条出库链路**，作业人员不需要在多个页面跳。

### 8.3.2.1 拣货任务

- **职责**：生成与执行拣货任务：按库位顺序排序优化路径，记录实际拣货库位/批次/序列号/数量，异常（缺货、破损）上报。
- **输入**：出库单明细；库存分配结果；作业人员或 PDA 扫码。
- **输出**：拣货任务与拣货明细（实际库位/批次/序列号）；缺货异常记录。
- **关系**：上游 = 8.3.1.2、7.2.1.2；下游 = 8.3.3.1、7 库存（已拣未发的占用状态）。**拣货完不等于已发货**：拣货只是把货从库位移到打包区，库存仍占用未释放。

### 8.3.2.2 波次与合并拣货

- **职责**：把多张出库单按规则合并成拣货波次，提高拣货效率：按承运商/库区/订单数合并，支持波次进度跟踪。
- **输入**：出库单集合；合并规则（承运渠道、库区、时段）。
- **输出**：波次任务 + 各出库单在波次中的位置。
- **关系**：上游 = 8.3.2.1；下游 = 8.3.3.1。**合并只影响拣货效率，不改变订单粒度**：波次完成后仍需按订单拆分复核与打包。

### 8.3.3.1 复核扫描

- **职责**：打包前复核：逐件扫描商品与订单核对，检出漏件/错件/多件，支持开箱复核（高价值订单）。
- **输入**：扫描记录（条码/序列号）；订单明细；复核规则。
- **输出**：复核通过/异常结果；异常单转人工处理。
- **关系**：上游 = 8.3.2.1/8.3.2.2；下游 = 8.3.3.2 打包。**复核是错发拦截的最后机会**，序列号商品必须逐件核对。

### 8.3.3.2 打包与称重

- **职责**：打包作业：选择包材、填充物、打印面单、称重与体积测量、记录包装尺寸（用于体积重与平台申报）。
- **输入**：复核结果；包材选择；称重数据；申报信息（3.7.2 物理属性）。
- **输出**：包裹记录（parcel + parcel_item）+ 实测重量体积。
- **关系**：上游 = 8.3.3.1；下游 = 8.3.4.1 发货、10 物流（取重算费）。**包裹必须含明细项**（哪些 SKU、多少件），只有重量和运单号无法追溯与对账（实体目录 §9）。

### 8.3.4.1 发货交接

- **职责**：发货交接：确认承运商与运单号、登记交接时间与交接人、扣减库存完成出库、触发物流轨迹与平台回传。
- **输入**：包裹与运单号；承运渠道；交接确认。
- **输出**：出库完成分录（预占转实扣）+ 发货事件 → 9 订单状态、10 轨迹、2 平台回写。
- **关系**：上游 = 8.3.3.2；下游 = 7 库存、9 订单、10 物流、2 渠道回写。**实发扣减与预占消费在同一事务**，避免预占悬空或重复扣减。

### 8.3.4.2 面单与标签打印

- **职责**：打印面单、装箱单、SKU 条码、库位标签、箱唛，支持批量打印、模板配置、打印次数记录（平台对重复打印有要求）。
- **输入**：打印任务（对象集合、模板）；打印机配置。
- **输出**：打印任务记录 + 打印内容（PDF/指令流）；打印日志。
- **关系**：上游 = 10 物流（面单数据）、3.1.2.3（条码）；下游 = 现场打印设备。**面单打印次数需记录**，部分平台对重复面单有明确规则。

### 8.4.1.1 组装单

- **职责**：实物套装组装：按 BOM 领用组件、消耗组件库存、产生成品 SKU 库存，同一事务完成。
- **输入**：成品 SKU 与 BOM 版本；组件领用量；组装数量。
- **输出**：组装单 + 组件出库分录 + 成品入库分录。
- **关系**：上游 = 6.4.1.1 加工单、3.5.2 BOM；下游 = 7 库存。**虚拟套装走不到这里**——虚拟套装不持有库存，出库时由 09 订单直接展开组件扣减。

### 8.4.2.1 拆解单

- **职责**：成品拆解回组件：消耗成品库存、产生组件库存（用于退换货拆解、样品回收）。
- **输入**：成品 SKU 与数量；拆解去向（可用/待检/残次）。
- **输出**：拆解单 + 反向库存分录。
- **关系**：上游 = 8.4.1.1；下游 = 7 库存、11 售后（退件拆解）。**拆解结果的组件质量状态由接收方决定**，不能默认全部回可售。

### 8.5.1.1 作业效率

- **职责**：统计仓库人效：人均日拣货件数/单量、拣货行走距离、打包时效、复核准确率、差错率，按人按日统计。
- **输入**：作业任务记录（操作人、时间、类型）；人员配置。
- **输出**：人效报表 + 排名 + 趋势。
- **关系**：上游 = 8.3 全部作业记录；下游 = 17 绩效。**人效数据用于提成核算与排班**，需明确口径避免争议（ERP 人效报表是绩效争议高发区）。

### 8.5.2.1 库位利用率

- **职责**：分析库位占用：容量利用率、周转率、空置库位、爆满库位、低效库位，给出调整建议。
- **输入**：库位与库存占用；出库频次。
- **输出**：利用率报表 + 热力图 + 建议。
- **关系**：上游 = 8.1.2.1；下游 = 8.1.2.2 自动分配优化。**库位热力数据同时优化拣货路径**（高频商品放近出口），一举两得。

### 8.5.3.1 出库时效

- **职责**：统计出库各环节时效：订单到出库时长、拣货时长、打包时长、交接时长，识别超时环节与瓶颈。
- **输入**：订单时间戳；各作业环节时间戳。
- **输出**：时效分布 + 瓶颈环节 + 超时明细。
- **关系**：上游 = 9 订单、8.3 作业记录；下游 = 1 工作台履约健康。**时效数据直接对应平台迟发率指标**，超时会导致绩效违规与搜索降权。
