# 13 利润与经营分析系统

> **定位**：回答"钱赚在哪、亏在哪、下一步该动什么"。所有数字必须能点进去看到构成，看不到构成的报表一律不做。
> **后端归属**：`reporting` 服务（基于事件构建的**可重建**投影，不是业务写入来源）。
> **前端入口**：`/analytics`

## 边界

**做**：经营看板、销量分析、产品表现、利润分析、库存分析、采购与物流分析、绩效分析、自定义报表与 BI、预警订阅。

**不做**：不产生业务事实、不做业务写入。报表是投影，**可从事件重建**；任何报表数字与业务系统冲突时，以业务系统为准。

**关键约束**：
- **口径唯一**：一个指标只允许一处定义，其他地方引用不允许重算
- **可下钻**：每个汇总数字必须能钻到构成明细（哪个订单、哪个 SKU）
- **时区与币种明确**：跨时区店铺汇总需显示所用时区，跨币种需显示折算汇率与时点
- **数据延迟要显示**：报表数据不是实时的，必须标明最近更新时间，否则用户会误判

## 详细设计

### 13.1.1.1 经营总览

- **职责**：展示公司/法人/店铺维度的核心经营指标：销售额、订单量、销量、毛利额、毛利率、广告花费、净利、退货率、库存总额、应收余额，支持时间对比与环比同比，显示数据更新时间。
- **输入**：报表投影数据；时间范围与维度选择；用户数据范围。
- **输出**：指标卡 + 趋势图 + 异常提示 + 下钻入口 + 数据更新时间戳。
- **关系**：上游 = 12 财务、9 订单、7 库存、14 广告；下游 = 13.2–13.5 各专题分析。**数据更新时间必须常驻显示**，用户看到的是 T-1 数据还是实时数据必须一目了然。

### 13.1.1.2 多店对比

- **职责**：多店铺横向对比：规模、增长、利润率、广告效率、退货率、库存周转，找出掉队店铺与增长店铺，支持按平台分组。
- **输入**：店铺维度聚合；对比指标选择。
- **输出**：对比矩阵 + 排名 + 差异归因提示。
- **关系**：上游 = 13.1.1.1；下游 = 各店铺的专题分析。**跨平台对比要处理口径差异**（亚马逊的 GMV 与 TikTok 的口径不同），对比时标注口径说明。

### 13.1.2.1 目标设定

- **职责**：设定经营目标：按部门/人员/产品/店铺设定销售额、毛利额、毛利率、广告 ROI、库存周转等指标与周期，支持分解到月/周。
- **输入**：目标定义（指标、目标值、周期、归属对象）；历史基线参考。
- **输出**：目标记录 + 分解计划。
- **关系**：上游 = 17 组织（部门人员）；下游 = 13.1.2.2 达成追踪。**目标要挂在组织对象上**（部门/人/店铺），否则无法与绩效核算对接（行业普遍需求）。

### 13.1.2.2 达成追踪

- **职责**：追踪目标达成：当前值、达成率、预测达成（按当前速度推算期末值）、未达标项高亮、人员/产品维度排名。
- **输入**：13.1.2.1 目标；实际值投影；时间进度。
- **输出**：达成率表 + 预测 + 预警。
- **关系**：上游 = 13.1.2.1；下游 = 17 绩效核算、1 工作台预警。**预测达成值比当前值更有管理价值**——月初就知道会不会达标，才有时间干预。

### 13.2.1.1 销量趋势

- **职责**：销量与销售额趋势：按日/周/月、小时维度查看，支持多维对比（同比/环比/店铺间/产品间）、异常日期标注（大促、缺货、断货）。
- **输入**：时间范围；维度与对比方式；异常事件标注。
- **输出**：趋势图 + 对比视图 + 异常标注。
- **关系**：上游 = 9 订单数据；下游 = 13.2.2、6.2.1 补货（销量预测输入）。**销量异常必须能关联事件**（大促、断货、价格调整），否则图表只是曲线没有洞察。

### 13.2.1.2 分时与分周模式

- **职责**：分析出单时间分布（按小时、按星期），识别高峰低谷，支持按此调整仓内人力与促销排期。
- **输入**：订单时间戳（按店铺时区换算）；时段配置。
- **输出**：时段分布热力图 + 高峰时段排序。
- **关系**：上游 = 9 订单；下游 = 8.5 作业排班、14 广告（分时投放）。**跨境多时区店铺必须按各自时区统计**，汇总时区不同会造成误判。

### 13.2.2.1 店铺与站点

- **职责**：按店铺、站点、平台维度拆解销量与销售额，含店铺增长贡献、新店/老店区分、渠道占比。
- **输入**：维度选择；时间范围。
- **输出**：分组报表 + 占比与贡献度。
- **关系**：上游 = 13.2.1.1；下游 = 13.1.1.2。**增长贡献度比绝对值有用**：告诉老板"哪个店/哪个品带来了增量"。

### 13.2.2.2 SKU/SPU/Listing

- **职责**：按商品维度拆解销量：SKU/SPU/Listing 三层，支持 SPU 汇总（多平台多 SKU 合并看）、变体销量分布。
- **输入**：商品维度；时间范围；是否合并 SPU。
- **输出**：商品销量报表 + 层级钻取。
- **关系**：上游 = 9 订单、3 商品主数据；下游 = 6 补货、5 定价。**SPU 口径是跨平台经营的基本单位**——只按平台 SKU 看会误判商品整体表现。

### 13.3.1.1 产品表现分析

- **职责**：单产品的 360 度分析：销量、销售额、毛利、流量、转化、退货、库存、库龄、广告表现、竞品对比，集成在同一页面滚动查看（避免页面来回跳）。
- **输入**：产品标识（SKU/SPU/Listing）；时间范围；对比基线。
- **输出**：多指标分析页 + 趋势 + 排名分位。
- **关系**：上游 = 全部业务域；下游 = 各业务域的处理页。**这是运营每天用得最多的页面**，性能与信息密度优先，指标要可对比（环比/同层级排名）。

### 13.3.1.2 生命周期与分层

- **职责**：按生命周期与表现分层商品：新品、爆款、旺款、平款、滞销款、衰退款，按 ABC 分类（销量/金额），输出分层结果与建议动作。
- **输入**：销量与毛利历史；分层规则配置。
- **输出**：分层结果 + 各层建议（备货/清仓/下架/推广）。
- **关系**：上游 = 13.3.1.1；下游 = 6.2.1.2 备货、5.4 调价、7.6.1 呆滞。**分层是资源分配的依据**：爆款备货、滞销清仓，没有分层就只能平均用力。

### 13.3.2.1 流量转化

- **职责**：分析流量与转化：曝光、点击、Session、转化率、客单价，区分自然与广告流量，计算转化漏斗。
- **输入**：平台流量数据同步；订单数据。
- **输出**：漏斗视图 + 转化率趋势 + 异常诊断。
- **关系**：上游 = 2 同步、14 广告；下游 = 13.3.1.1。**平台流量数据与内部订单数据口径不同**，展示时必须标注来源与统计范围（页面 vs 订单）。

### 13.3.2.2 关联营销效果

- **职责**：分析站外/关联营销（关联视频、A+、Store 导流、社交媒体）的引流效果：曝光、点击、加购、成交归因。
- **输入**：营销位配置与曝光点击数据；订单归因数据。
- **输出**：营销位效果报表 + ROI。
- **关系**：上游 = 4 刊登（营销模块）、14 广告；下游 = 13.3.1.1。**归因需要明确规则**（末次点击 vs 首次点击），否则各人看到的数不一样。

### 13.4.1.1 多模式利润报表

- **职责**：按经营模式（自发货/全托管/半托管/平台仓）分别出利润报表，支持按天/月、按 MSKU/SKU/SPU/店铺/订单多维度核算。
- **输入**：成本数据（12.4）、费用数据（12.3/12.4）、订单收入；模式标记（2.3.2.1）；汇率快照。
- **输出**：利润报表（收入 - 各成本费用 = 毛利）+ 多维下钻 + 口径说明。
- **关系**：上游 = 12 财务全部；下游 = 1 工作台、5 定价。**不同模式的利润含义完全不同**，混在一张表里会得出错误结论——必须在报表维度上区分。

### 13.4.1.2 SKU 利润

- **职责**：SKU 级利润明细：单品收入、采购成本、头程、平台费、物流费、广告费、退款损失、净利，支持查看构成瀑布与订单级明细。
- **输入**：SKU 维度；时间范围；成本分摊结果。
- **输出**：SKU 利润表 + 瀑布图 + 订单明细钻取。
- **关系**：上游 = 13.4.1.1、12.4.2.2；下游 = 5 定价、6 采购。**SKU 利润是选品、定价、采购谈判的共同依据**，口径一旦有争议三方都会不认账——因此口径必须在报表上写明。

### 13.4.2.1 成本结构

- **职责**：分析成本构成占比：采购/头程/平台费/物流/广告/退货/其他，按 SKU、店铺、类目、时间维度拆解，看成本结构变化趋势。
- **输入**：成本分摊结果；历史基线。
- **输出**：占比结构图 + 趋势 + 异常提示。
- **关系**：上游 = 12.4.2；下游 = 13.4.2.2。**成本结构变化比绝对值更有信号**：广告占比突然上升往往先于利润下滑发生。

### 13.4.2.2 费用差异

- **职责**：对比**预计费用与实际费用**的差异：平台费、物流费、广告费、头程分摊，按 SKU 与期间展示差异率，定位高估/低估的系统性偏差。
- **输入**：测算费用（5.2.3）；实际费用（12.3.1.2）；时间范围。
- **输出**：差异表 + 偏差趋势 + 规则调优建议。
- **关系**：上游 = 5.2.3 费用规则、12.3.1.2；下游 = 5.2.3（规则校准）。**持续为负的差异说明费用规则配错了**，长期不校准会让所有利润测算失准。

### 13.4.3.1 利润预警

- **职责**：利润异常预警：SKU 毛利转负、店铺利润率骤降、费用占比异常、广告亏损超标、订单级亏损订单占比突增。
- **输入**：利润指标投影；阈值规则配置。
- **输出**：预警清单 + 通知 + 处置入口。
- **关系**：上游 = 13.4.1.1；下游 = 1 工作台、5 调价、14 广告。**亏损订单占比是广告投放失控的早期信号**，比 ROAS 下降更早出现。

### 13.5.1.1 库存分析

- **职责**：库存分析报表：库存金额结构、周转率、库龄分布、缺货与超储、ABC 分类、呆滞占比，按仓库/类目/店铺拆解。
- **输入**：库存数据（7）；销售数据；盘点历史。
- **输出**：库存分析报表 + 图表 + 下钻。
- **关系**：上游 = 7 库存、9 订单；下游 = 6 采购、5 调价。**周转率必须按成本口径算**，用售价算会虚高——这是库存报表最常见的错误。

### 13.5.2.1 采购分析

- **职责**：采购分析：采购金额趋势与占比、供应商集中度、价格波动、到货准时率、采购周期、采购成本占销售额比。
- **输入**：采购数据（6）；供应商评级。
- **输出**：采购报表 + 趋势 + 供应商对比。
- **关系**：上游 = 6 采购与供应；下游 = 13.4 利润。**供应商集中度是供应链风险指标**，单一供应商占比过高会在断供时直接击穿业务。

### 13.5.3.1 物流分析

- **职责**：物流分析：单均运费、头程分摊后成本、渠道对比、时效达成率、各国成本对比、异常件占比。
- **输入**：物流数据（10）；成本数据。
- **输出**：物流报表 + 渠道对比。
- **关系**：上游 = 10 物流与头程；下游 = 5 定价（运费测算校准）、13.4 利润。**物流成本占比高的类目必须单独定价**，统一毛利率会吃掉利润。

### 13.6.1.1 自定义报表

- **职责**：业务人员自助构建报表：选择数据源（受控的语义层指标，不是直连库表）、维度、度量、筛选、图表类型、保存与共享、订阅推送。
- **输入**：报表配置；可用的语义层指标清单。
- **输出**：报表结果 + 分享链接 + 定时订阅。
- **关系**：上游 = 语义层指标定义；下游 = 13.6.2.1 导出。**只允许基于语义层指标自助，不开放任意 SQL**——否则报表口径会分裂成几十个版本，最终没人知道该信哪个。

### 13.6.1.2 看板搭建

- **职责**：搭建自定义经营看板：拖拽组件、选择指标与筛选、布局保存、按角色共享、设置默认值。
- **输入**：组件配置；看板模板；可见范围设置。
- **输出**：看板视图 + 共享配置。
- **关系**：上游 = 13.6.1.1；下游 = 1 工作台（可置为个人看板）。**看板需权限过滤**，不同角色看到的组件不同，不能一个看板通吃。

### 13.6.2.1 导出与订阅

- **职责**：报表导出（Excel/CSV/PDF）与定时订阅推送（邮件/企业 IM），支持大文件异步导出。
- **输入**：导出请求；订阅配置。
- **输出**：文件下载链接；订阅投递记录。
- **关系**：上游 = 13.6.1.1；下游 = 1.3.2.2 推送。**大导出走异步任务并给出有效期**，同步导出大文件会拖垮服务。
