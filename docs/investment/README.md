# 调研 / 探索笔记

本目录放**一次性**的技术调研、设计探索、可选方案对比笔记。

- 一次调研结束，结论落地后：本目录归档到 `archive/`
- 结论成为决策：升级为 `docs/decisions/000N-*.md`，本目录文件链接过去
- 结论纯探索 / 无落地：保留本目录供未来参考

## 命名

`YYYY-MM-DD-<topic-slug>.md`

## 跟 sessions/backlog 的区别

| 路径               | 性质               | 例子                     |
| ------------------ | ------------------ | ------------------------ |
| `docs/sessions/`   | 时间线上的会话记录 | "今天我们定了 XXX"       |
| `docs/backlog/`    | 已决定要做但还没做 | "未来要接入 PayPal"      |
| `docs/investment/` | 一次性探索         | "调研了三种 BI 方案对比" |
