# 业务设计审查与后续决策

更新：2026-09-30。范围：产品文档入口、蓝图公共规则及订单/库存/售后/财务关键闭环、IAM PRD、配套数据流。不是对全部 L4 模块或当前代码的全面验收。

## 已修正文档问题

| 优先级 | 问题与影响                                                  | 处理                                                              |
| ------ | ----------------------------------------------------------- | ----------------------------------------------------------------- |
| P1     | IAM 将未逐项验收的要求称为已发布，易误判安全能力            | 改为 In Review，区分代码入口存在与 AC 验收通过；补审计 FR         |
| P1     | 租户切换丢响应时保留旧身份，可能与服务端已切换状态冲突      | 未知时阻断操作并核验服务端身份                                    |
| P1     | 未发货直接取消，遗漏正在出库的竞态                          | 先停止作业、核验并释放；仅剩余数量可取消                          |
| P1     | 不可售 bucket 已排除又再次扣减，数量口径矛盾                | 区分 bucket 可用与汇总可售；缓冲只扣一次                          |
| P1     | 退款“失败释放”未区分超时，可能重复退款                      | 结果未知保留占用，仅确认未支付且终止后释放                        |
| P1     | 旧数据流沿用 apps/api、modules、固定 Kafka 与单一订单号去重 | 按服务事实归属重写，区分订单来源键和事件去重                      |
| P2     | 财务凭证同时支持反过账与“过账后只能红冲”                    | 统一为已过账不可改写，只能红冲                                    |
| P2     | 蓝图缺少可执行的跨模块验收                                  | 新增 D3–D4 闭环 Draft PRD，含 FR/AC、数量守恒、故障恢复及发布门槛 |

## 待决策与后续 PRD

下列项目没有被默认为已批准；负责人尚未指定，均由对应责任角色接手。

| 编号 | 未决项                                                | 责任角色             | 决策期限/交付物                                                  |
| ---- | ----------------------------------------------------- | -------------------- | ---------------------------------------------------------------- |
| R-01 | 首发仓型、法人/仓库范围、金额口径、预占时长与恢复时限 | 产品、仓储           | D3–D4 PRD 批准前，填写该 PRD 开放问题结论                        |
| R-02 | IAM 未保存内容保护、认证审计及跨标签页并发的实现证据  | IAM、安全            | IAM 批准前逐 AC 验收，差距转开发项；不以文档修改代替修复         |
| R-03 | D1–D2 店铺连接登记与真正平台授权/同步的交付界限       | 渠道产品             | 下一次渠道迭代前补 PRD，明确首个平台、授权撤销、重授权与未知结果 |
| R-04 | 代发是否承担货权、采购义务和资金责任                  | 采购、订单、财务产品 | 代发 PRD 批准前；“不经自有仓”不能自动推出“不入账、只算差价”      |
| R-05 | 应付确认、预付款、关账阻断项及成本方法变更的业务政策  | 财务产品             | 财务 PRD 批准前；蓝图不是会计政策或法律结论                      |
| R-06 | 多平台可售分摊、同步延迟和超卖风险容忍                | 库存、渠道产品       | D5 PRD 批准前；不能承诺仅靠缓冲即可杜绝外部超卖                  |
| R-07 | 后续各 L4 的自动动作幂等、金额/数量口径、超时恢复细化 | 各域产品             | 相应模块进入开发前，在 PRD 补齐；蓝图四项描述不等于可交付        |
