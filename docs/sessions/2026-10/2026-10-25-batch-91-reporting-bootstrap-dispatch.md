`adopt` 是为「老调度器遗留任务」设计的，**不建分支、不建 worktree、不分配版本号**，且 `baseSha` 取

本轮按 `plan` 的语义逐项补齐：

1. 分支 `feat/13-1-1-1` 从 `integration/module-dev`（`8ef8abbd`）切出；
2. worktree `.worktrees/13.1.1.1` 建立并 `pnpm install --prefer-offline`（3.4 秒）；
3. 迁移版本 **V376** 由 `usedVersions()` 口径确认空闲（集成头最大 V375）；
4. **`baseSha` 由 `76569eae`（父提交）改回 `8ef8abbd`（真实基线）** ⇒ `land` 的「无新提交不许落地」闸重新生效；
5. `sessionId` 显式写成 `batch-91-13.1.1.1`（非空）⇒ `laneIsUnclaimed` 不会把这条车道当成「无人认领的孤儿」在下轮重派。
