## 踩坑记录（本轮新增，建议写进 `SYNC-MAIN.md`）

⚠️ **abort 之后再取 stage-2/stage-3 会得到「全一致」的假阳性。**

本轮第一次做 prettier 比对时，`git merge --abort` **已经执行过**，索引里 stage 2/3 已被清掉：

```bash
git show ":2:$f" > o.$i   # ❌ merge 已 abort ⇒ 报错、输出空文件
```

空文件经 prettier 处理仍是空文件 ⇒ 两侧都为空 ⇒ `cmp -s` 全部判等
⇒ 得出「18/18 逐字节相同」的错误结论（其中 `api-proxy.ts` 实际**并不相同**）。

**正确做法**：abort 之后直接比两个分支的 tip：

```bash
git show "HEAD:$f"        > o.$i     # ours = 集成头
git show "origin/main:$f" > t.$i     # theirs = main
```

**并且必须加体积门槛**，否则空输出会把「取不到文件」伪装成「两侧一致」：

```bash
[ "$osz" -lt 50 ] || [ "$tsz" -lt 50 ] && 判为无效样本
```

本轮靠这道门槛才发现假阳性并重做（重做后结论为 17 相同 + 1 超集）。
⚠️ 另：`git show` 的错误输出别丢进 `/dev/null` 静默掉 —— 否则连「文件取不到」都看不见。
