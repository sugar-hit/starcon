# 合规

跨境电商涉及多国法规，本目录追踪合规约束与对应技术 / 流程措施。

## 法规清单

| 法规 | 适用 | 文档 |
|---|---|---|
| GDPR | 欧盟用户数据 | （待写） |
| CCPA | 加州用户数据 | （待写） |
| 中国《数据安全法》 | 国内业务 + 跨境数据出境 | （待写） |
| 中国《个人信息保护法》(PIPL) | 国内业务 | （待写） |
| SOC 2 Type II | SaaS 客户合同要求 | （待写） |
| ISO 27001 | 信息安全管理 | （待写） |
| PCI DSS | 支付卡数据 | （待写，如走第三方支付可豁免大部分） |

## 关键约束

- **数据出境**: 中国 / 欧盟用户数据出境走 SCC + 评估流程，详见 `data-export.md`（待写）
- **数据驻留**: 欧盟客户数据必须存储在 EU region
- **用户删除权**: SaaS 用户 / 平台买家都有删除权，软删 + 30 天硬删 pipeline
- **审计日志**: 不可篡改，留存 ≥ 5 年

## 当前状态

合规体系正在建设中，所有具体文档在编写后会按日期归档。
